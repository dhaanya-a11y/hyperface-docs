# Usage Limits

## Overview

**Usage Limits** define the maximum reward a customer can receive from an offer within a specified duration. They help control reward distribution by limiting how frequently a customer can receive rewards during the lifetime of an offer.

Unlike **Budget**, which controls the total reward allocation for an offer across all customers, **Usage Limits** apply at the customer level and determine how much an individual customer can earn within a configured period.

# Configure Usage Limits

A usage limit is configured using the following fields:

- **Duration**
- **Limit Type**
- **Limit Value**

Each configuration defines the maximum reward that can be issued to a customer during the selected duration.

---

## Duration

The **Duration** specifies the time period for which the configured usage limit remains applicable.

      className="w-[250px]"

Select one of the following duration options:

| Duration | Description |
|----------|-------------|
| **Day** | Applies the configured usage limit for one day. |
| **Week** | Applies the configured usage limit for one week. |
| **Month** | Applies the configured usage limit for one month. |
| **Billing Cycle** | Applies the configured usage limit for the selected billing cycle. |
| **Quarter** | Applies the configured usage limit for one quarter. |
| **Annual** | Applies the configured usage limit for one year. |
| **Life Time** | Applies the configured usage limit throughout the lifetime of the offer. |

**Example**

A bank wants to reward customers for grocery purchases but limit the rewards that can be earned every month. By selecting **Month** as the duration, the configured usage limit is applied over each monthly period.

---

## Limit Type

The **Limit Type** specifies the type of usage limit that should be applied.

The following limit types are available:

| Limit Type | Description |
|------------|-------------|
| **Both** | Applies both available usage limit types. |
| **Count** | Applies the configured count-based limit. |
| **Reward Points** | Applies the configured reward points limit. |

> **Note:** The UI lists these limit types. Their detailed business behaviour is not defined in the provided source.

---

## Limit Value

The **Limit Value** specifies the maximum value allowed for the selected **Limit Type** during the configured **Duration**.

**Example**

If the duration is set to **Month**, the configured limit value defines the maximum reward that can be issued to a customer during that monthly period.

---

## Multiple Usage Limits

Multiple usage limits can be configured for the same offer.

To add additional usage limits:

1. Click **Add More**.
2. Configure another usage limit.
3. Repeat the process until all required usage limits have been added.

This allows different usage limits to be configured for different durations or limit types within the same offer.

---

## Example

A bank launches a rewards campaign to encourage customer spending while ensuring that rewards remain within the campaign limits.

The issuer configures the following usage limit:

- **Duration:** Month
- **Limit Type:** Reward Points
- **Limit Value:** 5,000

With this configuration, customers can continue earning reward points for eligible transactions until the configured monthly limit is reached. Once the limit is reached, no additional rewards are issued during that monthly period.

---

## Complete the Configuration

After configuring the usage limits:

1. Review the configured **Duration**, **Limit Type**, and **Limit Value**.
2. Verify that all required usage limits have been added.
3. Click **Continue** to proceed to the **Posting** configuration.
