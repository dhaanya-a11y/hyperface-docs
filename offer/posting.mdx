## Overview

The **Posting** section defines when the configured offer benefit is credited to the customer's account and the conditions that must be satisfied before the benefit is posted.

After configuring **Usage Limits**, use this step to configure the posting behavior, posting eligibility, and the ledger narrations recorded during reward posting and reversal.

<Note>

**Posting** controls only how and when the offer benefit is credited. A customer must first satisfy all previously configured offer conditions before the configured posting rules are evaluated.

</Note>

---

## Enable Posting

Enable **Posting** to allow the configured offer benefit to be credited to eligible customers.

If **Posting** is disabled, the configured offer benefit is not credited even when all previously configured offer conditions are satisfied.

---

## Configure Posting Eligibility

Posting Eligibility defines the conditions that must be satisfied before the configured offer benefit is credited to a customer's account.

    <img
      src="/images/v.13.png"
      alt="Posting Eligibility"
      className="w-[700px]"
    />
  </div>
</div>

To configure posting eligibility:

1. Select the required **Attribute**.
2. Configure the corresponding value or values.
3. Select the appropriate **Action**.
4. Click **Add More** to configure additional posting eligibility conditions, if required.

The following posting eligibility attributes are available:

| **Attribute** | **Description** |
|---------------|-----------------|
| **Account Status** | Identifies accounts based on their current account status. |
| **Account Smart Tag** | Identifies accounts based on the Smart Tags associated with the account. |
| **Account Block Code** | Identifies accounts based on the assigned account block code. |

---

### Account Status

Use **Account Status** to configure posting eligibility based on the current status of an account.

<div className="my-8 flex justify-center">
  <div className="overflow-hidden rounded-2xl border border-gray-200 bg-white shadow-lg">
    <img
      src="/images/v.15.png"
      alt="Account Status"
      className="w-[700px]"
    />
  </div>
</div>

Configure the following:

- Select the required account status.
- Select the appropriate **Action**:
 - **Allowed** – Credits the configured offer benefit to accounts matching the selected account status.
- **Denied** – Does not credit the configured offer benefit to accounts matching the selected account status.
---

### Account Smart Tag

Use **Account Smart Tag** to configure posting eligibility based on the Smart Tags associated with an account.

<div className="my-8 flex justify-center">
  <div className="overflow-hidden rounded-2xl border border-gray-200 bg-white shadow-lg">
    <img
      src="/images/v.16.png"
      alt="Account Smart Tag"
      className="w-[700px]"
    />
  </div>
</div>

Configure the Account Smart Tag as follows:

1. Select **List** or **Input**.
2. If **List** is selected
- Select **Create New List** to create a new Account Smart Tag list, or
- Select an existing Account Smart Tag list.
3. If **Input** is selected, enter one or more Account Smart Tag values manually.
4. Select the required **Action**:
   -- **Allowed** – Credits the configured offer benefit to accounts associated with the selected or entered Account Smart Tag values.
   -- **Denied** – Does not credit the configured offer benefit to accounts associated with the selected or entered Account Smart Tag values.
---

### Account Block Code

An **Account Block Code** is an identifier assigned to an account to represent a specific account status or restriction.

Use this attribute to configure posting eligibility for accounts associated with the specified block code.

    <img
      src="/images/v.17.png"
      alt="Account Block Code"
      className="w-[700px]"
    />
  </div>

Configure the following:

- Enter one or more account block code values.
- Select the appropriate **Action**:
  - **Allowed** – Credits the configured offer benefit to accounts matching the specified account block code.
  - **Denied** – Does not credit the configured offer benefit to accounts matching the specified account block code.

<Tip>

Configure multiple posting eligibility conditions when rewards should be posted only after all required conditions have been satisfied.

</Tip>

## Configure Offer Posting

Choose when the configured benefit should be credited.

| **Posting Option** | **Description** |
|--------------------|-----------------|
| **Post Immediately** | Credits the benefit immediately after the configured posting conditions are satisfied. |
| **Schedule** | Credits the benefit according to the configured schedule. |

### Post Immediately

Choose **Post Immediately** when the reward should be credited as soon as all configured posting conditions are satisfied.

**Example**

Credit cashback immediately after an eligible transaction has been processed.

---

### Schedule

Choose **Schedule** when the reward should be credited at a later time or on a configured schedule.

**Example**

Credit monthly rewards on the first day of the following month.

<Warning>

Changing the posting schedule after an offer becomes active may affect when future rewards are credited. Review the selected posting option before publishing the offer.

</Warning>

## Configure Narration

Provide the ledger narration recorded during reward posting and reward reversal.

<div className="my-8 flex justify-center">
  <div className="overflow-hidden rounded-2xl border border-gray-200 bg-white shadow-lg">
    <img
      src="/images/l.1.png"
      alt="Configure Narration"
      className="w-[700px]"
    />
  </div>
</div>

Configure the following fields:

| **Field** | **Description** | **Example** |
|-----------|-----------------|-------------|
| **Posting Narration** | Narration recorded when the offer benefit is credited. |
| **Reversal Narration** | Narration recorded when a previously credited benefit is reversed. |

<Note>

Posting Narration and Reversal Narration are recorded for operational tracking and audit purposes. Use clear and meaningful descriptions so posted and reversed benefits can be easily identified.

</Note>
---

## What Happens After Configuration?

Once the configured posting conditions are satisfied, the offer benefit is credited according to the selected **Posting Option**.

If **Allow Reversal** is enabled, the configured **Reversal Narration** is used whenever a previously credited benefit is reversed.

---

## Complete the Configuration

After configuring **Posting**:

1. Verify that **Posting** is enabled, if required.
2. Review the configured **Posting Eligibility** conditions.
3. Confirm the selected **Posting Option**.
4. Review the configured **Posting Narration** and **Reversal Narration**.
5. Click **Continue** to proceed to **Display Elements**.
