## Overview

The Hyperface Dashboard provides a structured workflow for creating and configuring offers. Whether you're creating a **Transactional Offer**, **Milestone Offer**, **Merchant Offer**, **Gamified Offer**, or **Display Only Offer**, each offer follows a guided configuration journey that helps define every aspect of the offer before it is published.

Each configuration step focuses on a specific part of the offer, such as defining eligibility, configuring rewards, setting budgets, controlling reward distribution, and configuring customer-facing content. Completing each step ensures that the offer is fully configured and ready for publishing.

---

## Prerequisites

Before you begin creating an offer, ensure that you have the following:

- Access to the **Hyperface Dashboard**.
- A valid dashboard account with the required login credentials.
- Permission to create and manage offers.
- Access to the relevant **Issuer** and **Program**.
- The required offer configuration details, including eligibility criteria, reward configuration, budget settings, and display content.

---

## Offer Configuration Journey

The offer creation journey consists of the following configuration steps:

| **Configuration** | **Description** |
|-------------------|-----------------|
| **Offer Type** | Select the type of offer to be created. |
| **Outcome Type** | Select the reward or benefit that customers receive after satisfying the offer conditions. |
| **Offer Scope** | Configure the issuer, program, and applicability of the offer. |
| **Offer User Base** | Define the customers who are eligible for the offer. |
| **Eligibility** | Configure the conditions that determine whether a transaction, milestone, or activity qualifies for the offer. |
| **Offer Calculation** | Configure how the reward is calculated for eligible customers. |
| **Usage Limits** | Configure how frequently customers can receive rewards. |
| **Posting** | Configure when and how rewards are credited to eligible customers. |
| **Display Elements** | Configure the customer-facing information displayed for the offer. |

<Note>

The configuration journey varies based on the selected **Offer Type** and **Outcome Type**. Depending on your selections, certain configuration steps, fields, or options may differ. Complete each applicable step before publishing the offer.

</Note>
